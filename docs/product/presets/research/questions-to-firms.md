# Questions to prop firms (for the user to send)

| | |
|---|---|
| **Prepared by** | Lupa (Prop Firm Rules Researcher) |
| **Date** | 2026-10-23 |
| **Purpose** | Close the unknowns that official pages do not answer: personal-device rule, VPS conflicts, trading-day reset time, and whether a tool like All Win is allowed (classification U5) |
| **State** | Proposed. Nothing here has been sent. The user sends each block and keeps the firm's written answer. |
| **Basis** | Open items in the 18 research files and `consolidation-vps-platforms-gaps.md` after R4 |

How to use: paste one block into the firm's support chat or e-mail. Ask for the answer **in writing** and save it with the date; chat answers are weaker evidence than a help-center article or the terms. Send from the registered account e-mail. Do not include passwords or account credentials.

**Check before sending:** the shared description of All Win below must match what the user will actually run. Adjust the wording if it does not.

> Shared description (already inside each block): "All Win is software that runs on my own computer inside NinjaTrader 8. It receives trade instructions that I create (for example from my own TradingView alerts) and places them as orders on my own account. I stay in control and can stop it at any time; it never trades other people's accounts."

Firms with no device or hosting question left (Top One Futures, Topstep) only get the automation question.
